# 🌳 Ambiental SaaS - Backend

Backend robusto e escalável para a plataforma Ambiental SaaS, construído com FastAPI.

## 📚 Documentação

A documentação detalhada foi reorganizada para facilitar o desenvolvimento e manutenção:

*   [**Setup Inicial**](docs/SETUP.md): Instalação, Setup Wizard e configurações iniciais.
*   [**Autenticação e Segurança**](docs/AUTH.md): Detalhes sobre login, JWT, multi-tenancy e criptografia.
*   [**Arquitetura**](docs/ARCHITECTURE.md): Estrutura do projeto, modelos de dados e tecnologias.
*   [**Integração N8N**](docs/INTEGRATIONS.md): Guia de integração com IA e processamento de documentos.
*   [**Deploy e Migração**](docs/DEPLOYMENT.md): Checklists para produção e guias de migração de banco.

## 🚀 Quick Start

1.  **Clone e Instale**:
    ```bash
    git clone <repo>
    pip install -r requirements.txt
    ```

2.  **Setup Automático**:
    ```bash
    python setup.py
    # Acesse http://localhost:8001
    ```

3.  **Execute**:
    ```bash
    python main.py
    # Swagger UI: http://localhost:8000/docs
    ```
