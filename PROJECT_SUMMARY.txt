┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 COMO COMEÇAR                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Execute a migration:
     $ cd Backend && alembic upgrade head

  2. Configure N8N:
     • Importe os 5 workflows
     • Crie credenciais (saas-postgres, gemini-api)
     • Ative os workflows

  3. Configure backend (.env):
     N8N_WEBHOOK_URL=https://seu-n8n.com/webhook
     FILE_ENCRYPTION_KEY=<gerar>

  4. Teste:
     $ curl https://seu-n8n.com/webhook/admin/health

  ✅ Sistema operacional em ~15 minutos!
